# Medusa UI 正式迭代原始需求

来源：`docs/spec/product/ROADMAP.md` 9.2 与 `docs/spec/product/PRD.md` §7。

目标：以 UI 主路径完成一轮真实的 Medusa 游客结账自动化。访客选择已锁定种子中的黑色 S 码 T 恤，加入购物车，使用折扣码 `ARGUS10`，并验证折扣后的金额来自实时种子价格和折扣规则。自动化必须在 Chromium 中执行，覆盖桌面 `1440×900` 与移动 `390×844` 的关键可见状态，形成 R→T→C→nodeid 追踪链、运行证据与最终 PR 验收。

约束：

- 不登录客户账户，以游客身份操作。
- 商品、地区、币种、库存、配送、支付和折扣均使用 `shared/testdata/seed-registry.yaml` 声明的真实种子，不硬编码派生总额。
- 页面交互遵循 POM 边界与语义定位器顺序；测试文件不直接写定位器。
- 正向场景之外，需要验证一个不会削弱正向要求的负向或边界行为。
- 是否必须完成到“订单创建成功”，还是以“进入结账并确认折扣后购物车总额”为本轮成功边界，需由用户明确决定。
